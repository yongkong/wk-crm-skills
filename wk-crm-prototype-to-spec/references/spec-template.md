## 第 1 章：模块概述

### 1.1 业务背景
- 描述业务场景：谁在什么场景下做什么操作
- 2-3 段文字，说明业务痛点和系统解决思路

### 1.2 模块定位
- **入口**：菜单路径（独立菜单 / Tab页 / 补充入口）
- **核心实体**：主表 PO 类名 + 表名
- **关联模块**：列出所有关联模块（用括号标注英文类名）
- **数据隔离**：数据归属规则（如：每条记录属于某一条主单据）
- **分类/类型**：如有多种类型，说明划分维度

### 1.3 核心流程
- 用 ASCII 流程图展示端到端业务流程
- 区分不同发起方式的流程路径
- 标注关键节点（审批、同步、回调）

```
发起方A → 入口A → 创建单据 → 编辑 → 提交审批
发起方B → 入口B → 确认单据 → 编辑 → 提交审批
                                    ↓
                              审批流（N级：...）
                                    ↓
                          通过 → 同步 ERP / 外部系统
                          驳回 → 状态=审批驳回
                          撤回 → 状态=已撤回
```

## 写作规范

### 文档语言
- 全文中文
- 技术术语保留英文（如 PO、BO、Controller、Service）
- 字段名用 camelCase（Java）或 snake_case（数据库）

### 表格规范
- 每张表有编号序号列
- 状态列使用 emoji 标记（✅ ⚠️ ❌）
- 关联字段标注来源表/类

### ASCII 线框图规范
- 用 `┌─┐│└─┘` 字符绘制
- 标注按钮用 `[按钮名]`
- 标注输入框用 `[          ]`
- 标注下拉用 `[请选择▼]`
- 标注 Tab 用 `[Tab1][Tab2]`

### 代码引用规范
- PO 类引用：`CrmXxxYyy.java`（`@TableName("wk_zj_xxx_yyy")`）
- Controller 引用：`/crmXxxYyy` 前缀
- 字段引用：`javaPropertyName`（`db_column_name`）

### 版本管理
- 文档头部标注版本号和日期
- 变更说明列出本章修改内容
- 附录 C 记录跨版本差异
