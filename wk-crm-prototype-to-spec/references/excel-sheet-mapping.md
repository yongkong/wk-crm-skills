# Excel Sheet 列映射

> 6 个 Sheet 与 Markdown 章节的精确列映射关系。

---

## Sheet ① 模块基础信息

**数据来源**：MD 第一章

| 列 | 列名 | 填写内容 |
|----|------|---------|
| A | 参数名 | 固定值（模块中文名/模块英文名/CrmEnum.type/菜单基址/主键字段名/编号字段名/是否需要审批流/表单渲染模式/参考模块/需求文档路径/原型截图路径/蓝湖原型URL/备注） |
| B | 参数值 | 从原型提取或用户输入 |
| C | 填写说明 | 简要说明 |

**必填参数**（8 项）：模块中文名、模块英文名、CrmEnum.type、菜单基址、主键字段名、编号字段名、是否需要审批流、表单渲染模式

## Sheet ② 主表字段

**数据来源**：MD 第二章 2.1

| 列 | 列名 | 填写内容 |
|----|------|---------|
| A | 字段名(英文) | snake_case 数据库字段名 |
| B | 字段显示名(中文) | 中文显示名 |
| C | 数据库类型 | varchar/int/bigint/decimal/date/datetime/text |
| D | 必填 | 是/否 |
| E | 默认值 | 自动编号/NULL/0/CURRENT_TIMESTAMP |
| F | 是否系统字段 | 是=系统自动/否=业务字段 |
| G | 说明 | 字段用途说明 |

**注意**：
- 系统字段（9个）已在模板中预填，不可修改
- 业务字段从第 12 行开始填写
- 模板中第 12 行可能有合并单元格，需先 unmerge 再填写

## Sheet ③ 表单字段

**数据来源**：MD 第三章

| 列 | 列名 | 填写内容 |
|----|------|---------|
| A | 字段名(英文) | camelCase 字段名 |
| B | 显示名(中文) | 中文显示名 |

| D | 必填 | 是/否/空 |
| E | 选项/规则 | SELECT 选项逗号分隔，或"精度:N"，或空 |
| F | 列表显示 | 是/否 |

| H | 说明 | 字段用途说明 |

**注意**：
- formType 必须使用 `module-registry.md` §FieldEnum type 中的标准值
- 中集定制类型：kh(260)/jtContract(261)/jtOrder(222)/goodsRepository(213)/normalInvoice(233)
- 从第 3 行开始填写

## Sheet ⑥ 页面与权限

**数据来源**：MD 第五、六章

| 列 | 列名 | 填写内容 |
|----|------|---------|
| A | 配置项 | 列表Tab/列表默认字段/头部批量操作-转移/头部批量操作-删除/头部批量操作-导出/是否需要详情页/额外权限按钮/授权角色 |
| B | 值 | 逗号分隔的值 |
| C | 可选值/说明 | 简要说明 |

**标准配置项**（8 项）：
1. 列表Tab — 通常：全部,我负责的,下属的,我关注的
2. 列表默认字段 — 从表单字段中选择列表显示的字段
3. **头部批量操作-转移** — 是/否（多选后工具栏显示"转移"按钮）
4. **头部批量操作-删除** — 是/否（多选后工具栏显示"删除"按钮）
5. **头部批量操作-导出** — 是/否（多选后工具栏显示"导出"按钮）
6. 是否需要详情页 — 是/否
7. 额外权限按钮 — 如：作废,撤回
8. 授权角色 — 默认：管理员(全部)

**注意**：头部批量操作需在 `index.vue` 中实现 `handleOperations` 计算属性，通过 `EventsObj` 构造操作列表。若模块 `realm` 与 `crmType` 不一致，需用正确的 realm key 查权限。
