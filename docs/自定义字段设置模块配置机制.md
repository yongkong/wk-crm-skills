# 自定义字段设置 — 模块配置机制

## 概述

"系统设置 > 客户管理 > 自定义字段设置"页面中展示的模块列表，**不是前端静态配置的**，而是通过后端接口动态返回。核心数据流：

```
CrmEnum 枚举定义
    ↓
CrmFieldServiceImpl.queryFields() — sortMap 过滤 + 排序
    ↓
API: POST /crmField/queryFields
    ↓
前端 customField/index.vue 渲染模块列表
    ↓
点击"编辑" → label→moduleType 映射 → 跳转字段设计器
```

---

## 一、后端：模块列表的生成

### 1.1 接口入口

**文件**: `zhongjicheliang/crm/crm-web/src/main/java/com/kakarote/crm/controller/CrmFieldController.java`

```java
@PostMapping(value = "/queryFields")
public Result<List<CrmFieldsBO>> queryFields() {
    List<CrmFieldsBO> fieldsBOList = crmFieldService.queryFields();
    return Result.ok(fieldsBOList);
}
```

### 1.2 核心逻辑 — sortMap

**文件**: `zhongjicheliang/crm/crm-web/src/main/java/com/kakarote/crm/service/impl/CrmFieldServiceImpl.java`

`queryFields()` 方法的处理流程：

1. 从 `wk_crm_field` 表按 `label`（模块类型编号）分组查询，获取每个模块的最后更新时间
2. 通过 **sortMap**（硬编码的 `Map<Integer, Integer>`）进行过滤和排序
3. **只有在 sortMap 中注册过的 label 才会出现在前端列表中**
4. 模块显示名通过 `CrmEnum.parse(label).getRemarks() + "管理"` 生成

```java
// sortMap 示例
sortMap.put(CrmEnum.PRODUCT_FEATURE.getType(), 1);     // 产品特征管理
sortMap.put(CrmEnum.PRODUCT_TAG.getType(), 2);          // 产品标签管理
sortMap.put(CrmEnum.KH.getType(), 7);                   // 客户管理
sortMap.put(CrmEnum.JT_CONTRACT_CHANGE.getType(), 234); // 合同变更管理
// ...
```

### 1.3 CrmEnum 枚举

**文件**: `zhongjicheliang/crm/crm-common/src/main/java/com/kakarote/crm/constant/CrmEnum.java`

每个枚举值包含：

| 属性 | 说明 |
|------|------|
| `type` (Integer) | 模块类型编号，即前端所说的 `label` |
| `remarks` (String) | 模块名称（支持国际化） |
| `initIndex` (boolean) | 是否需要初始化索引 |

关键方法：
- `getTableName()` — 获取对应的数据库表名（如 `JT_CONTRACT_CHANGE` → `crm_zj_jt_contract_change`）
- `isZjBusinessTable()` — 判断是否为中集业务表（决定表名是否加 `zj_` 前缀）
- `getPrimaryKey()` — 获取主键字段名

### 1.4 返回数据结构

**BO**: `zhongjicheliang/crm/crm-common/src/main/java/com/kakarote/crm/entity/BO/CrmFieldsBO.java`

| 字段 | 类型 | 说明 |
|------|------|------|
| `label` | Integer | 模块类型编号 |
| `sort` | Integer | 排序权重 |
| `updateTime` | String | 最后修改时间 |
| `name` | String | 模块显示名称 |
| `languageKeyMap` | Map | 国际化 key |

## 二、前端：模块列表的展示

### 2.1 模块列表页

**文件**: `dz-zhongji/src/views/admin/crm/customField/index.vue`

- 调用 `customFieldIndexAPI()` 获取模块列表
- 渲染为 `el-table`，表格列：模块图标、模块名称、更新时间、操作（编辑）
- 点击"编辑"时通过 `handleCustomField()` 方法跳转

### 2.2 API 定义

**文件**: `dz-zhongji/src/api/admin/crm.js`（第187行）

```javascript
export function customFieldIndexAPI(data) {
  return request({
    url: 'crmField/queryFields',
    method: 'post',
    data: data
  })
}
```

### 2.3 label → moduleType 映射

**文件**: `customField/index.vue` 的 `handleCustomField()` 方法

前端将后端返回的 `label`（整数）映射为路由参数 `type`（字符串），用于跳转字段设计器：

```javascript
// 标准 CRM 模块
1: 'crm_leads',
2: 'crm_customer',
// ...

// 中集扩展模块（200+）
200: 'crm_product_feature',
234: 'crm_jt_contract_change',
// ...
```

### 2.4 图标映射

**文件**: `customField/index.vue` 的 `getLableIcon()` 方法

```javascript
200: 'wk wk-product-feature',
234: 'wk wk-contract-line',
// ...
```

## 三、前端：字段设计器

### 3.1 字段设计器页

**文件**: `dz-zhongji/src/views/admin/fields/index.vue`

三栏布局：
- **左侧**：字段类型库（拖拽到中间画布）
- **中间**：表单画布
- **右侧**：字段属性配置面板

### 3.2 title 映射

`title` 计算属性中将 moduleType 映射为中文标题：

```javascript
crm_jt_contract_change: '合同变更管理',
// ...
```

### 3.3 可选的特殊配置

| 配置项 | 说明 |
|--------|------|
| `isFieldLibDisabledModule` | 不允许从字段库拖入字段的模块黑名单 |
| `showLogic` | 是否启用逻辑表单（条件显隐） |
| `initCom()` | 过滤该模块可使用的字段类型 |
| `systemFields.js` | 系统字段中文名映射 |

## 五、新增模块的完整注册清单

要让一个新模块出现在"自定义字段设置"列表中并正常工作，需要在 **5 个位置** 同步注册：

| # | 位置 | 文件 | 操作 |
|---|------|------|------|
| 1 | **CrmEnum 枚举** | `CrmEnum.java` | 添加新枚举值（type、remarks 等） |
| 2 | **后端 sortMap** | `CrmFieldServiceImpl.java` 的 `queryFields()` | 添加 `sortMap.put(CrmEnum.XXX.getType(), 排序权重)` |
| 3 | **前端 label→moduleType** | `customField/index.vue` 的 `handleCustomField()` | 添加 `label: 'crm_xxx'` |
| 4 | **前端图标** | `customField/index.vue` 的 `getLableIcon()` | 添加 `label: 'wk wk-xxx'` |
| 5 | **前端 title** | `fields/index.vue` 的 `title` 计算属性 | 添加 `crm_xxx: 'XXX管理'` |

### 常见遗漏后果

| 遗漏位置 | 后果 |
|----------|------|
| sortMap | 模块列表中完全看不到该模块 |
| CrmEnum | 后端报错或模块名称显示异常 |
| label→moduleType | 点击"编辑"后跳转错误页面或白屏 |
| 图标映射 | 模块图标显示为默认图标 |
| title 映射 | 字段设计器页面标题显示为 moduleType 字符串 |

## 六、数据库表

### 字段定义表

**表名**: `wk_crm_field`  
**实体类**: `zhongjicheliang/crm/crm-common/src/main/java/com/kakarote/crm/entity/PO/CrmField.java`

关键字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `field_id` | bigint | 主键 |
| `label` | int | 模块类型编号，关联 CrmEnum.type |
| `field_name` | varchar | 字段名（代码中使用） |
| `name` | varchar | 字段显示名 |
| `type` | int | 字段类型（对应 FieldEnum） |
| `update_time` | datetime | 最后修改时间 |
| `company_id` | bigint | 企业ID（多租户隔离） |
