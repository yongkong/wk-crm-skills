# 项目数据库表结构全景分析

## 概览

| 维度 | 数据 |
|------|------|
| 数据库总数 | 5 个 |
| 表总数 | ~592 张 |
| 核心业务库 | zj_crm（552张） |
| 最大模块 | 中集定制CRM业务（65张）+ 中集产品配置（54张） |
| 自定义字段体系 | 14张字段配置表，支撑全模块动态字段 |
| 审批流体系 | 37+6=43张表，完整的流程引擎 |
| 业务表单 | 20+种申请/审批表单（报价、提车、发货、开票等） |
| 架构特点 | EAV模式存储扩展字段 + 独立数据表（`_data`后缀）存储字段值 |

## 数据库清单

| 数据库 | 表数量 | 说明 |
|--------|-------|------|
| zj_crm | 552 | 主业务库 |
| wk_crm_nacos | 13 | Nacos 配置中心 |
| wk_crm_seata | 4 | Seata 分布式事务 |
| xxl_job | 8 | XXL-JOB 定时任务 |
| bi（独立） | 15 | BI 商业智能（已合并到主库） |
